# DevSync

A modern full-stack developer collaboration platform built using the MERN stack with real-time communication, secure authentication, and scalable architecture.

---

#  Features

-  JWT Authentication & Authorization
-  OAuth Login Integration
-  Real-Time Chat using Socket.io
-  Email Notifications for Login Activity
-  Password Hashing & Protected Routes
-  RESTful API Architecture
-  Responsive UI Design
-  Fast Frontend with React + Vite
-  Modern UI using Tailwind CSS
-  MongoDB Database Integration

---

#  Tech Stack

## Frontend
- React.js
- Tailwind CSS
- Framer Motion
- Axios
- Vite

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Socket.io
- bcrypt.js
- Nodemailer

#  Project Overview

DevSync is designed to help developers communicate and collaborate in real time through a secure and modern platform. The application includes authentication systems, real-time messaging, API handling, and responsive UI components.

The project focuses on practical full-stack development concepts including:

- Authentication & Security
- Backend API Development
- Real-Time Communication
- State Management
- Database Integration
- Frontend UI/UX Design

#  Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/devsync.git
cd devsync
```

## 2️⃣ Install Dependencies

### Frontend

```bash
cd frontend
npm run dev
```

### Backend

```bash
cd backend
node server.js
```

---



---

#  Run the Project

## Start Backend

```bash
cd server
npm run dev
```

## Start Frontend

```bash
cd client
npm run dev
```
